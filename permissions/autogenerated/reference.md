## Default Permission

Default permissions for the plugin

#### This default permission set includes the following:

- `allow-open-android-video-player`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`android-player:allow-open-android-video-player`

</td>
<td>

Enables the open_android_video_player command without any pre-configured scope.

</td>
</tr>

<tr>
<td>

`android-player:deny-open-android-video-player`

</td>
<td>

Denies the open_android_video_player command without any pre-configured scope.

</td>
</tr>
</table>
